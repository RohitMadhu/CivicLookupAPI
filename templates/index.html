🏛️ Civic Lookup API

Welcome to the Civic Lookup API - your gateway to accessing information about federal and state officials, congressional districts, and financial disclosures.

Available Endpoints

GET /v1/lookup/zip/{zip_code}

Look up congressional districts by ZIP code

GET /v1/lookup/address

Look up districts by full address

GET /v1/divisions/{division_id}/officials

Get officials for a specific division

GET /v1/sources/status

Get status and metadata about data sources

GET /health

API health check
